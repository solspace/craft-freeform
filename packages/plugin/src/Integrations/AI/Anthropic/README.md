# Anthropic Integration

This integration allows you to use Anthropic's AI models for processing form submissions.

## Setup

1. Get your API key from [Anthropic Console](https://console.anthropic.com/)
2. Configure the integration with your API key
3. Select the model you want to use (default is `claude-haiku-4.5`)
4. Configure max tokens, and cache settings

### Recommended Models

- ⚡ `claude-haiku-4.5` — fast + cheap
  - Lightweight tasks
- ⚖️ `claude-sonnet-4.6` — best
  - Most use cases
- 🧠 `claude-opus-4.6` — smartest
  - Deep reasoning / critical tasks

## Usage

Once configured, you can add AI fields to your forms and select this integration to process the form data.
