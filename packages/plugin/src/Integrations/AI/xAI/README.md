# xAI Integration

This integration allows you to use xAI's AI models for processing form submissions.

## Setup

1. Get your API key from [xAI Console](https://console.x.ai/)
2. Configure the integration with your API key
3. Select the model you want to use (default is `grok-4.1-fast`)
4. Configure max tokens, and cache settings

### Recommended Models

- ⚡ `grok-4.1-fast` — fast + cheap
  - High-volume / low latency apps
- ⚖️ `grok-4.1` — balanced
  - General use, improved accuracy/personality
- 🧠 `grok-4.20` — smartest
  - Advanced reasoning / agent workflows

## Usage

Once configured, you can add AI fields to your forms and select this integration to process the form data.
