# Gemini Integration

This integration allows you to use Google's Gemini AI models for processing form submissions.

## Setup

1. Get your API key from [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Configure the integration with your API key
3. Select the model you want to use (default: gemini-1.5-flash)
4. Configure max tokens, temperature, and cache settings

## Usage

Once configured, you can add AI Summary fields to your forms and select this integration to process the form data.
