# Gemini Integration

This integration allows you to use Google's Gemini AI models for processing form submissions.

## Setup

1. Get your API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Configure the integration with your API key.
3. Select the model you want to use (default is `gemini-3-flash`).
4. Configure max tokens, temperature, and cache settings.

### Recommended Models

- ⚡ `gemini-3-flash` — fast + cheap
  - Most workloads
- ⚖️ `gemini-3-pro` — more capable
  - Larger / more complex tasks
- 🧠 `gemini-3.1-pro` — smartest
  - Hard reasoning / planning

## Usage

Once configured, you can add AI fields to your forms and select this integration to process the form data.
